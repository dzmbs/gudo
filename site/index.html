Build the new onboarding flow

Close the laptop. The work goes on.

Your sessions keep running

Shells and agents run on your host, not in the app. Lose signal, close the lid or switch devices. When you come back, the pane is where you left it, scrollback and all.

Agents on your phone

Gudo knows when Claude Code or Codex is working, done, or waiting on you. Approve, deny or reply from the inbox, or straight from the lock screen.

End to end encrypted. No accounts.

Your devices talk to your hosts directly, encrypted end to end. There is nothing to sign up for. When a relay is needed, it passes along packets it cannot read.

Native on iPad, iPhone and Mac

Swift and Metal on Ghostty's terminal core. Splits and every shortcut on iPad, a key bar made for agents on iPhone, real windows on the Mac.

Set up in a minute.

01

Install the host

On a Mac, the app has it built in. On a Linux server, run one command, or let the app install it over SSH.

02

Pair

Run gudo-hostd pair and scan the code. From then on, only devices you paired can connect.

03

Connect from anywhere

Gudo finds a direct path when it can and uses a relay when it can't. No ports to open, no VPN to set up.

curl -fsSL https://gudo.dev/install.sh | sh
