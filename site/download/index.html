Linux host

For servers, VMs and home boxes. One static binary, x86_64 or arm64. No root needed.

Install the host

Any recent Linux. systemd optional.

Install the host on Linux

There are two ways. Both end with gudo-hostd running as your user, ready to pair.

With one command

Run this on the server, as the user whose shell you want:

curl -fsSL https://gudo.dev/install.sh | sh

The script finds the build for your CPU in the latest GitHub release, checks its SHA-256, and puts gudo-hostd in ~/.local/bin. It doesn't use sudo or touch anything else. Read the script before you run it.

Then start it as a service and pair your device:

gudo-hostd service install
gudo pair

pair prints a QR code and a one-time ticket that lasts 10 minutes. Scan the code in Gudo, or paste the ticket. To keep the host running after you log out and start it at boot, run once:

sudo loginctl enable-linger $USER

From the app

Add the server with its SSH address, like you@server. Gudo connects over plain SSH first. Choose Install Helper and the app uploads gudo-hostd, checks it, starts it, and moves the host over. Next time it connects directly.

By hand

Every release has static binaries and a checksum file:

SystemFile
Linux x86_64gudo-hostd-x86_64-unknown-linux-musl
Linux arm64gudo-hostd-aarch64-unknown-linux-musl
ChecksumsSHA256SUMS

Download from the latest release, check it with sha256sum -c SHA256SUMS --ignore-missing, make it executable, and put it on your PATH as gudo-hostd.

Use a Mac as a host

The Mac app already includes gudo-hostd. In Settings, under This Mac, turn on Keep Sessions Running in the Background. Then pair your iPhone or iPad with it.
